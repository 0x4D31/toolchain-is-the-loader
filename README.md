# The Toolchain Is the Loader

Slides from my Objective by the Sea 2026 talk, “The Toolchain Is the Loader: Attributing Malicious Developer Artifacts on macOS.”

**[View the slides](https://0x4d31.github.io/toolchain-is-the-loader/)**

The talk uses six public cases to show how to trace activity by a trusted developer tool back to the artifact that supplied the code. Use the arrow keys to move through the deck, **Sources** for the references, and **Backups** for the appendix.
